# thenot-lab.github.io

Dominion Labs' public landing pages, served by GitHub Pages from `main` at
**https://thenot-lab.github.io/**.

## Layout

| Path | Purpose |
|---|---|
| `index.html` | Main landing page — "Dominion Labs — Building What Matters" |
| `security_consulting.html` | Security consulting offering page |
| `eli_guardian.html` | Eli Guardian page |
| `companion_bot.html` | Companion bot page |
| `eli-os/` | Eli OS pages |
| `brain-stack/` | Brain-stack pages |
| `handoffs/` | Published handoff documents |

## Working on it

Static HTML/CSS — no build step. Edit the file, push to `main`, and GitHub Pages
redeploys. There is no CI in this repo; the Pages build is the only gate.

## Note

This repository is **public**. Everything committed here is world-readable —
do not add secrets, internal handoffs, or client material.
